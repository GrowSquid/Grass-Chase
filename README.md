# Touch Grass
Welcome to the GrowSquid's third ever Hackclub Project!  
I have created a game in HTML to attempt to do the hardest possible thing as a programmer  
## How to Play
Select the Start button to begin the game and start the timer
Hover your cursor over the grass to attempt to graze it  
Reload the page to try again
## Features  
A 15s timer  
Attempt counter  
Moving background  

## Deployment  
Open via Github Pages:  
https://growsquid.github.io/Grass-Chase/  
OR  
Download the source files directly, including the images   
and run in a browser of your choice
